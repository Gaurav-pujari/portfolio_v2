Who's Viewed Your Portfolio
0  visits recorded on this device
How this works: every time someone opens your portfolio, this device/browser logs the time, page, referrer, device type, browser, and a best-effort approximate location (city/ISP from a free IP lookup) — no login or personal info required from the visitor. Because this is a static site with no server, each browser only sees its own visits. To see visits that happen on someone else's phone or laptop (e.g. an HR recruiter opening your link) in this same log, connect a free cloud sync:
  1. Create a free bin at jsonbin.io and copy its Bin ID + X-Master-Key.
  2. Open app.js, find CLOUD_SYNC_URL / CLOUD_SYNC_KEY near the visitor-analytics section, and paste them in.
  3. Redeploy — every visit anywhere will now sync to that shared bin automatically.
Until that's set up, this log shows visits made from this browser only (great for testing).
